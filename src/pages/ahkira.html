Why ahkira doesn't run at home

I wanted a chat box on this site that answers questions about my work. My own GPU could run the model fast enough. I decided not to use it, and this is why.

Attack cases
81, all pass
Unit tests
70
Path into my house
None

ahkira is the helper on this site. Before any code got written it had three rules: it can't put my home network at risk, it can't start sharing things it shouldn't, and when a visitor shows up it has to work. Plumbing and guard rails came first. The name and the mascot came last.

The first plan: run it on my own card

The obvious move was my gaming PC. RTX 3080, 12 GB, and I had just benchmarked it. A 30-billion-parameter mixture-of-experts model did about 43 tokens a second with only half of it on the card. A 14B model did about 72. Plenty for a chat. So the plan was: model on my PC, a tunnel from the website to it, no hosting bill.

Why I didn't

The model was fast enough. The tunnel was the problem.

  • It opens the house. A public endpoint that ends at my PC is a live path from the internet onto my home network. That machine holds my personal files.
  • It ties the site to my home. Anything that links a public page to where I live is a real risk.
  • It isn't always on. That PC sleeps, reboots and plays games. A visitor would hit a dead box.
  • Abuse lands on my power bill. Anyone abusing it would be running my GPU, with nothing in front to slow them down.

My other GPU box was worse. It runs the house's voice assistant and sits next to the backups. So instead of promising to be careful, I set it up so nothing in my house is reachable from this site.

What runs instead

Your question goes to a small hosted server outside my house, running an open-source model. My home network isn't part of it.

  • The page works without the model. Eleven common questions have fixed answers that I checked, and they work with JavaScript off. Only a question you type goes to the server. If the server is down, the page says ahkira is napping and the fixed answers still work.
  • Nothing private to leak. Besides your question, the model only sees the public pages of this site, after a filter strips anything sensitive. No private notes, nothing personal, and I never trained or tuned it on anything of mine. This is the rule that actually keeps me safe.
  • Guards in front. A bot check, per-visitor and daily limits, short questions, short answers, a hidden tripwire for anyone fishing for its instructions, a reply checker, and an off switch.
  • Chats are saved. The page says so above the box: they are kept so ahkira can get better, and may be used to train a later version. Emails and phone numbers get blanked before anything is stored, and a saved chat never goes back into what the model reads.

Trying to break it

The 3080 still got used, as the test machine. Same server code, run locally against the same family of model, fake secrets planted as bait, and scripted attacks thrown at it: jailbreaks, attempts to pull out its instructions, leak attempts, plain abuse.

Then two frontier AI models took turns playing attacker, two rounds each. Every trick that worked got fixed and became a permanent test. The suite is now 81 attack cases, all passing, plus 70 unit tests.

Round two also showed a weak spot. The reply checker, the filter that scans answers before they go out, is basically a word list. The attacker got 56 of 62 reworded attempts past it. So the checker isn't what keeps things safe. What keeps things safe is that there's nothing private in what the model reads in the first place. That's why I say "81 attacks, no leaks" and never "it can't be tricked."

Small things that bit me

  • The hosted model "thinks" by default. It used up its whole answer budget thinking and came back empty until I turned that off.
  • It copied an example sentence from its own instructions word for word and tripped the echo guard. Its instructions don't include sentences it could copy anymore.
  • The bot check fails in a headless browser, so the end-to-end tests run in a visible one.

Where it stands

ahkira is live. Before it went public it ran privately on the real setup, every refusal path was checked, and every live test turn passed. What's done and what's still planned is on the ask page, next to the box.
