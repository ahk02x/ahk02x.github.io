01 / Network

Network

Switching
An Aruba Instant On 1930 managed switch.
WiFi
An ASUS ROG GT-AX6000 working as the access point, picked up on Facebook Marketplace for 200 bucks.
What it counts
Traffic inside the house and traffic leaving it are kept as two different facts, because a house full of IoT devices should have to explain itself. How that works.

The photo is the shelf where every cable run in the house lands. The switch sits in a stand I designed and 3D-printed as two complete halves, left and right, that fit together around it. It is in two pieces because my printer was not big enough to print it in one, so I did the most I could with the tools available to me. The open lattice sides keep air moving, the cables route neatly underneath, and the access point sits on top. These are the two halves as I modelled them.

The fit and the size were right on the first try. I will admit it still needed some hand modification: the braces, and the joint where the two pieces connect, had clearance issues I missed, despite thinking I had caught everything. The right move would have been more virtual testing or a reprint, but I didn't want to waste the filament. After some cutting it got the job done, it works really well for the current setup, and it still looks amazing.

02 / Firewall

The firewall is my dad's 2011 PC.

blackwall is a Dell Vostro 460 turned into an OPNsense firewall. It was my dad's daily driver until I built him a new system, and then it sat in storage for three years. Opened up, it is as plain as it looks: one Sandy Bridge i5, 8 GB, no graphics card, nothing exotic. The photo is the first day I opened it up, with the original Dell power supply still in it.

One philosophy I keep coming back to is doing more with less, and this box fit a firewall perfectly. All it needed was a network card: a dual-port Intel I350 gigabit NIC, bought new on Amazon for 60 bucks, so it has a port for the internet and a port for the house.

The original supply later died and took the whole house's internet with it. I bought a Corsair RM650x for it on Facebook Marketplace, 65 bucks with all the cables and the original box. For airflow, a spare fan is zip-tied to the front, jank style. It is all about putting the spare parts I have to the best use I can. That is the entire repair history of the machine that runs the network.

Rescuing hardware is the point, not a constraint. Everything it does, from DNS and DHCP to counting the traffic, is software I can read, on a box that was sitting in storage.

03 / Servers

jarvis is the one that matters.

I had all the parts for a long time and never got around to putting them together. I finally did, and it became a home server I can back things up to and run jobs on. The photo is the day it came to life.

The one part I did buy was the CPU. I had one already, but I picked up a Ryzen 5 5600GE on Facebook Marketplace for 140 bucks instead. It is a 35 W chip, and for a machine that is always on, running cool matters more than running fast.

It runs Proxmox VE with Home Assistant and seventeen containers: a local language model, speech-to-text, Git hosting, a file share, the car's data pipeline, and a small HashiCorp lab where Nomad schedules the services.

CPU / RAM
Ryzen 5 5600GE (35 W), 64 GB DDR4: four 16 GB Crucial Ballistix sticks.
GPU
An RTX 2070 SUPER. The graphics card is there for the model and the transcription, not for games.
Storage
A 1 TB NVMe for the system, and three 4 TB IronWolf drives in RAIDZ1: about 6.9 TB usable, all on ZFS, so one drive can fail without taking the pool.
Idle
About 111 W, which is the number I actually watch, because it never turns off.
Upgrade
It went from 32 to 64 GB in November. The containers had been promised more memory than the box had, and the language model kept hitting its limit.
04 / sentry

The box that runs the room.

sentry is an Intel N5105 mini PC with 8 GB, and its job is the room rather than the network: the wall display, the Stream Deck and the lights. Keeping it off jarvis means the room can be rebooted without touching anything the house depends on.

It used to be my dad's firewall, until it died and I took it. I took it apart, got it to boot without the fan and troubleshot it from there. The easy fix was a five-dollar fan from AliExpress, but where is the fun in that? So I started designing my own stand, with a fan in the base that blows air up into the RAM and the CPU. The moment it was finished it looked like a robot, so I called it sentry.

In the photo the stand sits on top of blackwall. That stack is the most honest picture of this setup I have: a palm-sized mini PC balanced on a fifteen-year-old tower, and between them they run the place.

06 / Stack

Almost all of it is open source.

Not on principle alone. Open source is what lets a box be mine to read, change and keep running after the company behind it loses interest — which is the whole point of running it at home. Where something closed does the job better, it is named here too.

Virtualisation
Proxmox VE on jarvis, with Debian containers for the services. ZFS for the pool, so a drive can fail without taking the data.
Network
OPNsense on blackwall for DNS, DHCP, firewalling and traffic accounting. Tailscale joins my own machines to each other without opening a port to the internet.
House
Home Assistant runs the lights, the TV and the rest, against my own code rather than each vendor’s cloud.
Code
Git, and GitHub for the public repositories. Every change to this site opens a pull request, and GitHub Actions runs the build and the tests on it before I merge.
This site
Static HTML built by a Python script with no dependencies, served by GitHub Pages. The ask page runs on a Cloudflare Worker, with Cloudflare Turnstile as the bot check.
Writing it
Python for nearly everything, SQLite where data needs to stay, OpenSCAD for anything that gets printed, and systemd and launchd to run jobs on a schedule.
07 / Next

Where it's going.

I love building and changing up hardware, so the next step is a rack, and everything migrates into it: a proper server chassis, PoE switches, enterprise or consumer, whatever it turns out to be, and a standalone NAS so the storage is resilient on its own. Then an offsite backup.

The direction is hybrid. My personal data and the house's IoT automation stay local, on hardware I own. Heavy compute comes from subscriptions or frontier models when I need it. Alongside that I want my own local AI that I train myself, on a modest setup sized for my own workloads and projects, with room to grow. It already has a name, ahkira.
