About

Amir Khademi (full name Amir Hossein Khademi) is a Site Reliability Engineer based in Toronto, Canada. He has spent his career in infrastructure and operations: Linux fleets, Kubernetes, observability, incident response, and the automation that keeps on-call quiet.

Outside work he runs his own fleet of a few Proxmox containers, a Raspberry Pi and a Mac, and uses it as a place to try ideas that are too risky for production: an alert board that an AI coding agent is required to acknowledge before it can end its turn, a file-based memory system with a linter and nightly verification, a wall display that latches alarms until a human clears them, and a vehicle data logger built from a reverse-engineered diagnostic cable.

He writes about this work at ahk02x.dev and publishes code at github.com/ahk02x.

Contact: amir@ahk02x.com. Text is better than a phone call.
