About

Amir Khademi

Full name Amir Hossein Khademi, also written Amir-Hossein Khademi. Site Reliability Engineer, Toronto, Canada.

I have spent my career in infrastructure and operations: Linux fleets, Kubernetes, observability, incident response, and the automation that keeps on-call quiet.

Outside work I run a fleet of my own, a few Proxmox containers, a Raspberry Pi and a Mac, and use it to try ideas that are too risky for production: an alert board that an AI coding agent must acknowledge before it can end its turn, a file-based memory system with a linter and nightly verification, a wall display that latches alarms until a human clears them, and a vehicle data logger built from a reverse-engineered diagnostic cable.

I write about this work here and publish code at github.com/ahk02x. Contact: amir@ahk02x.com. Text is better than a phone call.
